# Poker — «Дві горили»

Казино «Дві горили» знову повертається — і тепер у нас покер.

Якщо рулетка й слоти вам уже підкорилися — настав час перевірити свою інтуїцію та холодний розум у справжній картковій битві.

Грайте проти дилера, збирайте комбінації та доведіть, що саме ви — король столу.

##  Опис 

Poker "Дві Горили" — консольна C#-програма, що симулює класичну покерну роздачу «гравець проти дилера». Програма роздає карти, визначає комбінації, порівнює їх між собою та обирає переможця. Гравець може робити ставку, програма обраховує виграш або програш та оновлює баланс. Покер реалізовано повністю через логіку комбінацій: від пари до стріта, фул-хауса і каре.

 ##  Можливості

1) Випадкова роздача карт та неможливе їх повторення

2) Автоматичне визначення всіх покерних комбінацій

3) Чесне порівняння комбінацій гравця та дилера

4) Баланс гравця

5) Повтор гри

6) Простий консольний інтерфейс

##  Як запустити

1) Відкрити файл 01.sln у Visual Studio.

   Виконати Build.

   Запустити проєкт (Start).

2) Або запустити готовий 01.exe у папці bin/Debug.

##  Вимоги

1) Windows

2) .NET Framework (версія підтягується автоматично Visual Studio)
